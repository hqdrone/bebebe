# Повторялка

Пиксельный дразнилка для малышей: ребёнок говорит в телефон, а персонаж повторяет фразу смешным голосом. Кнопки нажимать не нужно: приложение само слышит, когда фраза закончилась.

**Играть:** https://hqdrone.github.io/bebebe/

## Как пользоваться

1. Откройте ссылку в Chrome на Android и нажмите **«Играть»**. Разрешите доступ к микрофону.
2. Говорите. Пока вы говорите, персонаж слушает («Слушаю…»), а когда вы замолчите, он повторит («Бе-бе-бе!»).
3. Нажмите на персонажа, и он повторит последнюю фразу ещё раз.
4. Внизу можно выбрать другого персонажа, и последняя фраза сразу прозвучит его голосом:
   Белочка, Мышка, Медведь-великан, Робот, Пришелец, Чудище, Попугай-эхо и кубик «Случайно».
5. **Чувствительность:** если персонаж срабатывает сам по себе (шумно), сдвиньте ползунок влево. Если он не слышит тихий голос, сдвиньте вправо. Настройка и выбранный персонаж запоминаются.

Совет: громкость телефона лучше сделать средней. Если динамик очень громкий, а комната гулкая, сдвиньте чувствительность чуть влево.

## Добавить на главный экран Android

1. Откройте https://hqdrone.github.io/bebebe/ в **Chrome**.
2. Нажмите меню **⋮** в правом верхнем углу.
3. Выберите **«Добавить на главный экран»** (или **«Установить приложение»**), затем **«Установить»**.
4. На главном экране появится значок с белочкой. Приложение откроется на весь экран без адресной строки и будет работать без интернета.

## Устройство

Статический сайт без сборки и зависимостей: чистые HTML/CSS/JS и Web Audio API.

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | экран и пиксельный стиль |
| `app.js` | микрофон, голоса (playbackRate, ring-модуляция, эхо), анимация, Wake Lock |
| `vad.js` | детектор речи по громкости: адаптивный шум, предзапись 0.35 с, конец после 0.9 с тишины |
| `sprites.js` | 8 персонажей 32×32, нарисованных кодом из палитры на 12 цветов |
| `sw.js`, `manifest.json`, `icons/` | PWA и офлайн |
| `tools/test-vad.js` | офлайн-тест детектора: `node tools/test-vad.js фраза.wav` |
| `tools/make-icons.js` | генерация иконок из спрайта: `node tools/make-icons.js` |

Локальный запуск: `python3 -m http.server`, затем откройте http://localhost:8000. Микрофон работает только на localhost или по https.
